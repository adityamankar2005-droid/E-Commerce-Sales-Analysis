🛒 E-Commerce Sales Analysis
📌 Project Overview

This project focuses on analyzing an e-commerce dataset to understand sales performance, profitability, customer segments, product categories, and regional trends.
The analysis combines Python (EDA & insights) and Power BI (interactive dashboard) to support data-driven business decision-making.

🎯 Business Objectives

Analyze overall sales and profit performance

Identify high-performing and low-performing product categories

Understand customer segment contribution to sales

Evaluate regional profitability

Monitor key business KPIs such as profit margin and order volume

🛠️ Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Power BI – Interactive dashboard

Jupyter Notebook

📂 Dataset Description

The dataset contains transactional e-commerce data including:

Order details and datescustomer information

Product categories and sub-categories

Sales, profit, discount, and quantity

Region and shipping mode

Order dates

(Dataset used for learning and portfolio purposes.)

📊 Analysis Performed (Python)

Data cleaning and preprocessing

Feature engineering (Month, Year, Profit Margin)

Sales and profit trend analysis

Category and sub-category performance analysis

Customer segment analysis

Regional sales and profit analysis

Identification of loss-making categories

📈 Power BI Dashboard

An interactive Power BI dashboard was built to visualize key insights and KPIs.

Dashboard Highlights:

KPIs: Total Sales, Total Profit, Total Orders, Profit Margin

Sales contribution by customer segment

Profit by region

Sales by product category

Interactive slicers for category and ship mode

🔍 Key Insights

Consumer segment contributes the highest share of total sales.

Technology category generates the highest sales revenue.

Certain sub-categories show consistent losses despite high sales.

Western region contributes the highest profit among all regions.

Discounts have a noticeable impact on profitability.

💡 Business Recommendations

Optimize discount strategies for loss-making sub-categories.

Focus marketing efforts on high-performing customer segments.

Improve profitability in underperforming regions.

Review shipping strategies to reduce cost impact.

Prioritize high-margin product categories.

✅ Conclusion

This project demonstrates an end-to-end e-commerce data analysis workflow, combining Python-based exploratory analysis with Power BI dashboarding.
The insights derived can help businesses improve sales strategy, profitability, and customer targeting.
